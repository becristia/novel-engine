# UI 工作台验收记录

北京时间 2026-10-30 03:20，P0～P7 已完成。八页由真实 React 组件和本地接口构成，操作落到已有 SQLite、工作流、版本与统一提交服务。主视觉沿用概念图的深绿导航、暖白画布、正文阅读区、来源侧栏和状态色。

## 启动与复现

在仓库根目录执行：

```bash
npm ci
npm run web -- --library ./books
```

打开终端显示的本机地址，默认 http://127.0.0.1:3917 。配置模型、登记已有工作区和编译后启动方式见 [README](../../README.md)。默认配置可以管理作品、导入导出和离线检查；生成与审稿需要显式配置模型或离线响应文件。

离线浏览器验收使用独立临时数据库与 `tests/browser/server.ts` 的固定响应：

```bash
npm run check
npm test
npm run build
node dist/cli/main.js doctor --offline
npm run test:web
```

测试服务使用端口 3918，运行时自动创建临时作品。测试流程通过真实接口生成计划、候选、报告与修改组，引用身份来自核心实际提供的来源；测试适配器仅属于验收代码。无需修改生产配置或提供真实凭据。

收尾补充的回归先复现失败，再验证修复：

- 登记和后续读取均拒绝 `novel.db` 及 SQLite 日志的符号链接，包含失效链接；不能借文件链接绕过作品目录边界。
- 历史与导出要求明确的非负安全整数版本，缺失、空白、小数、负数和越界值均拒绝，避免静默选择版本 0。
- 静态资源缺失返回 404，错误编码及空字符路径返回 400，非读取方法返回 405；站点图标随前端构建提供。
- 弹窗显式设置初始焦点并在关闭后恢复；Esc 先经过作者确认，拒绝放弃时仍保留编辑。只填写新章标题也视为未保存修改。
